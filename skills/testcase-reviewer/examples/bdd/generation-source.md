# 生成场景的来源示例

## 用户故事

作为一名已注册用户  
我希望重置密码  
从而重新访问我的账户

## 验收标准

1. 用户可以从登录页面请求密码重置。
2. 系统会向用户已验证的电子邮箱发送重置链接。
3. 有效的重置链接允许用户设置新密码。
4. 已过期的重置链接会被拒绝，并显示明确提示。
5. 密码重置成功后，用户可以使用新密码登录。
6. 验收标准未定义再次请求密码重置是否会使此前的链接失效。

## 场景生成请求示例

```text
请根据这个用户故事和验收标准生成一个 BDD 特性文件。
包含主路径和过期链接拒绝路径。
将尚未解决的假设单独列出，不要臆造行为。
```
