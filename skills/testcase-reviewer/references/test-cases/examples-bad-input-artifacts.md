# 不合格输入材料示例

在正式评审之前，需要识别低质量输入材料时，使用此参考资料。示例有助于识别歧义、薄弱追溯、过载套件和不完整测试材料，然后再使用其他示例文件中的质量阶梯。

1. 不合格需求：业务规则含糊

## 1. 不合格需求：业务规则含糊

### 材料

```text
REQ-11：重要客户在可能的情况下应获得更好的折扣。
```

### 问题所在

- `重要` 没有定义
- `更好的折扣` 没有定义
- `在可能的情况下` 没有定义
- 无法直接测试

### 对评审的影响

- 将此需求标记为含糊
- 不要臆造预期值
- 要求确认客户分类、折扣金额和判断条件

## 2. 不合格需求：缺少反向行为

### 材料

```text
AC-07：用户可以上传 PDF 文档。
```

### 问题所在

- 没有文件大小规则
- 没有无效文件类型的处理方式
- 没有重复上传的处理方式
- 没有失败提示的预期

### 对评审的影响

- 追溯评审必须说明来源判定依据缺少反向路径预期
- 覆盖结论应标明受限

## 3. 不合格需求集：规则互相矛盾

### 材料

```text
REQ-21：订单金额超过 50 EUR 时可享受高级配送。
AC-21.2：仅当购物篮金额高于 50 EUR 时才可选择高级配送。
```

### 问题所在

- “超过 50 EUR”根据具体解释，可能包含 50.00
- “高于 50 EUR”通常不包含 50.00
- 边界规则存在矛盾

### 对评审的影响

- 在评审测试覆盖前指出边界歧义
- 避免将恰好 50.00 EUR 的测试用例误判为失败

## 4. 不合格追溯矩阵：映射不可用

### 材料

```text
REQ-01 -> 已测试
REQ-02 -> 已测试
REQ-03 -> 部分覆盖
```

### 问题所在

- 没有测试用例 ID
- 没有套件引用
- 没有覆盖理由
- 无法支持审计追踪

### 对评审的影响

- 将追溯标记为不充分
- 要求提供明确的测试链接，例如 `REQ-03 -> TC04, TC05`

## 5. 不合格追溯矩阵：夸大完整性

### 材料

```text
AC-10 -> TC09
```

### 问题所在

- 一个链接就暗示已完整覆盖
- 没有说明是否覆盖 MSS、EXT 或 ERR 路径
- 没有指出缺失的替代结果

### 对评审的影响

- 检查链接的用例是否只覆盖成功路径
- 不要接受“一条链接就等于完整覆盖”的假设

## 6. 不合格用例草稿：缺少判定依据

### 材料

```text
标题：TC05 计算税费
前置条件：
- 服务已部署
步骤：
- 发送请求
预期结果：
- 税费正确
```

### 问题所在

- 没有需求 ID
- 没有输入值
- 没有计算规则
- 没有可衡量的输出目标

### 对评审的影响

- 将其判定为技术描述薄弱且无法追溯
- 要求提供来源规则和明确的数值断言

## 7. 不合格用例集：只有成功路径

### 材料

```text
UC08 TC01：MSS - 使用有效凭证登录成功
UC08 TC02：MSS - 使用已记住的设备登录成功
UC08 TC03：MSS - 修改密码后登录成功
```

### 问题所在

- 没有无效凭证用例
- 没有账户锁定用例
- 没有 MFA 失败用例
- 表面上看覆盖面广，仍然遗漏了高风险路径

### 对评审的影响

- 覆盖评审应明确指出缺少 ERR 和 EXT 场景

## 8. 不合格套件结构：底层套件过载

### 材料

```text
密码重置
- 34 条用例，涵盖令牌过期、令牌复用、用户不存在、用户锁定、限流、邮件模板检查、本地化和审计日志
```

### 问题所在

- 一个底层套件混合了过多行为
- 难以搜索和维护
- 容易造成重复测试
- 与实现类或自动化类的映射薄弱

### 对评审的影响

- 建议按有意义的行为分组拆分
- 标记可维护性与冗余风险

## 9. 不合格套件结构：扁平且不透明

### 材料

```text
测试
- TC01
- TC02
- TC03
- TC04
```

### 问题所在

- 没有组件分组
- 没有测试类型分组
- 没有判定依据或需求分组
- 单看层级无法理解结构

### 对评审的影响

- 声称套件质量良好前，至少应按组件或测试类型进行组织

## 10. 不合格评审输入包：材料不足以签核

### 材料

```text
已有：
- 7 条手工测试用例草稿

缺少：
- 需求
- 验收标准
- 套件结构
- 优先级或测试级别
```

### 问题所在

- 缺少可靠判定依据
- 无法确认覆盖完整性
- 没有签核依据

### 对评审的影响

- 继续进行有限的结构与技术评审
- 明确说明覆盖和追溯结论是暂定的
