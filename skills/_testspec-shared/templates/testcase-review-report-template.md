# 评审报告模板

需要形成正式书面评审时使用此模板。

## 执行摘要

1. 总体评估等级
2. 主要优点
3. 严重问题
4. 建议优先级

## 需求分析与追溯

1. 需求清晰度评估
2. 需求到测试的追溯矩阵
3. 已识别的风险和依赖

## 测试套件结构评审

1. 层级评估
2. 组织结构建议
3. 重复与缺口分析

## 覆盖分析

1. 需求到测试的映射摘要
2. 覆盖指标
3. 测试设计方法使用情况
4. 缺口与过度测试分析

## 技术正确性验证

1. 判定依据是否恰当
2. 测试逻辑一致性
3. 数据质量评估

## 规范符合性评审

1. 模板遵循情况检查清单
2. 标题质量评估
3. 可选字段使用情况

## 辅导与提升计划

1. 优点
2. 提升空间
3. 针对性提升项
4. 具体辅导建议

## 评分矩阵

1. 需求覆盖
2. 技术正确性
3. 规范符合性
4. 测试设计成熟度
5. 文档质量
6. 整体质量

## 行动计划

1. 执行前立即采取的行动
2. 短期目标
3. 长期提升事项

## 元数据

1. 评审人
2. 评审日期
3. 评审耗时
4. 后续跟进日期（如需要）
